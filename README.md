# Aurelia Scientific Calculator

A dark scientific calculator inspired by the capabilities of the Casio fx-570EX. It uses React, Vite, Tailwind CSS, and shadcn/ui components.

## Features

- Scientific expressions with natural input
- Degree, radian, and gradian angle modes
- Trigonometry, logarithms, roots, powers, factorials, permutations, and combinations
- Exact fraction and decimal display
- Answer recall and memory storage
- Calculation history
- Desktop and mobile layouts
- Keyboard input

## Local development

```bash
npm install
npm run dev
```

Run the test suite and production build with:

```bash
npm test
npm run build
```
